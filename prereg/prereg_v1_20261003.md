## 一、假设(预注册)

- **H1(方向不稳定复现)**:HacRED 解码交互 Γ_F1(金标承载校准)在扩展至 15 种子后,
  逐种子方向仍不一致(符号一致率 < 0.8),且混合符号种子的 Γ 值分布与同符号种子可分。
- **H2(层级梯度)**:对照量的种子间标准差随"效应路径上的随机源层级"(1–4)单调上升
  (Spearman ρ > 0.5,单侧;层级编码见第四节,已按 9 个既有对照先行校准,故此验证为
  **半预注册**——层级编码已在既有数据上观察,新增数据集上的复制才是预注册部分)。
- **H3(跨基准复制)**:层级→稳定性的梯度方向在 SciERC/MAVEN/DocEE 三个新基准上复现
  (各基准内最高层级对照的种子间 SD > 最低层级对照的种子间 SD)。
- **H0(无效即报告)**:若任一假设不成立,如实报告并相应收缩论文主张,不调整编码或种子。

- L4 双重差分或校准×训练种子(随机源复合)

## 修订 2(2026-10-03,LLM 钩子实验启动之前——本节在任何 LLM 推理之前冻结)

**新增实验 D5:LLM 时代的契约敏感性(钩子实验)**

- **动机**:预判审稿质疑"LLM 时代 DocRE 评测是否过时";同时检验评价契约敏感性
  是否**跨越范式**(微调编码器 → ICL 大模型)。这是本文通向主会的关键增量。
- **模型(冻结)**:主模型 Qwen2.5-7B-Instruct(Apache-2.0,hf-mirror 可达,24GB 显存内
  FP16 确定性推断);鲁棒性模型 Llama-3.1-8B-Instruct。温度 0(greedy),不采样。
- **数据(冻结)**:DocRED 开发 498 篇(既有冻结契约:189,556 候选、gD/gR 金标、
  earliest-mention 分组);4-shot 提示,示例固定取自 DocRED 训练拆分前 4 篇
  (示例选择规则:与前 2 篇开发文档标题哈希最近邻,确定性好复现)。
- **对照矩阵(冻结,全部在**同一批 LLM 预测**上审计)**:
  - L1 计分单位:A(hit-any)vs R(逐金标)vs F1 的句内—跨句差距,同预测换计分;
  - L2 换金标:Gap_F1(gD)−Gap_F1(gR),固定 LLM 预测——即 P3M 实验的 LLM 复刻;
  - L3 提示契约:同一模型、两种输出格式(JSON 三元组 vs 自由文本后解析)——
    作为"提示即契约"的敏感性演示(探索性);
  - 不做的:阈值校准(LLM 输出为离散集合,无阈值维度,如实声明)。
- **解析与违规处理(冻结)**:LLM 输出三元组经实体名精确匹配回连到候选键;
  落在候选全集之外的三元组计为契约违规并报告比例(>5% 则该设置标 unverifiable);
  幻觉实体名不强行匹配,单独统计。
- **假设(预注册)**:
  - H-L1:同一批 LLM 预测在 A 与 R 两种计分下的差距读数符号不一致(事后诊断,预期成立);
  - H-L2:固定 LLM 预测换金标(gD vs gR)使 F1 差距移动 |Δ| ≥ 0.02(与 P3M 量级可比);
  - H-L3:提示格式契约改变 Γ 方向或量级 ≥0.02(探索)。
- **成本**:cloud-a 单卡,推断约 1–2 h,≈¥2。
- **边界**:单模型规模(7B)、单数据集(498 篇)、greedy 解码;不声称代表全部 LLM 行为。

## 修订 3(同日,Sharper takeaway 条款——写入 ARR 英文稿的终版核心句)

**中文(供结语/宣传语)**:「句内—跨句差距的符号不是模型或数据集的固有属性——同一批预测
换计分即翻转,换金标即移动,跨训练种子的单次读数接近符号随机;只有冻结比较契约之后,
差距才从噪声变成证据。该结论对微调编码器与指令 LLM 同样成立。」

**English (ARR abstract/closing)**: "The sign of the intra–inter gap is not a property of
models or datasets: holding predictions fixed, it flips with the scoring unit and the gold
standard; across training seeds, single-seed readings of the decoding interaction are close
to sign-random. Without a frozen comparison contract, gap changes are uninterpretable — and
this holds for instruction-tuned LLMs as much as for fine-tuned encoders."

**使用纪律**:此句式中"接近符号随机"仅限 HacRED 交互的 5 种子证据,不得泛化到全部对照;
"翻转"一词仅指已观测的读数变化,不暗示机制因果。

## 修订 5(2026-10-03,三项加固实验在任何一项计算之前)

### R1 排名翻转演示(rank-flip)

- **目的**:把主张从"差距读数敏感"加固为"模型排序在合法契约间不保"。
- **模型清单(冻结,全部为库内既有预测,不新增训练)**:X2(多标签,种子池 5→10)、
  ATLOP-PE8(校准泄露修复版)、ATLOP-formal(正式协议版)、P3M(原生决策规则桥接,5 种子)。
  公开预测文件(DocuNet/DREEAM dev)若可得,须在计算任何排名**之前**登记追加;
  之后的追加一律不允许。
- **契约集(冻结)**:(i) 计分 A vs R;(ii) 固定预测换金标 gD vs gR;
  (iii) 阈值变体(仅对有连续分数的模型)。排名量 = Gap_F1(句内−跨句);
  种子口径:种子平均为主,逐种子并列报告。
- **判定**:存在至少一对模型 (i,j) 与一对契约 (c1,c2),使
  sign(Gap_i^c1 − Gap_j^c1) ≠ sign(Gap_i^c2 − Gap_j^c2);并报告契约间排名的 Kendall τ。
- **半预注册声明**:X2 与 ATLOP 的方向差异在 E3 已观察;本实验冻结的是模型清单与
  契约集,防事后挑选。若未观察到任何翻转,如实报告"这些契约下排名稳定"。

### R2 种子数收敛分析

- **目的**:把 H1 转化为可操作结论——"交互符号判定至少需要几个种子"。
- **种子子序列(冻结)**:n ∈ {2,3,5,8,12,15}(X2 为 {2,3,5,8,10})。
- **重抽样(冻结)**:C(15,n) ≤ 10000 则全组合,否则随机 10000 组(种子 20260926)。
- **输出(冻结)**:每 n 的池化 Γ 符号分布、|Γ| 的 SD、池化估计 95% CI 排除 0 的子集比例;
  交付"符号判定所需最小种子数"曲线。
- **定位**:描述性分析,无接受/拒绝门槛;结论句式预冻结为
  "交互符号判定至少需要 N 种子(95% 子集 CI 排除 0)",N 由数据给出,不在本文预设。

### R3 切片稳健性(事后分层,无需预注册门槛但冻结切片清单)

- **切片(冻结,仅此 3 维)**:关系频次四分位(按 DocRED 训练集实例数)、
  文档长度四分位(按句数)、实体对句距(1 / 2–3 / ≥4)。
- **对象**:库内全部既有预测集(X2/ATLOP 双版/P3M,各 5 种子);零训练。
- **输出**:每切片内的 L1 换计分翻转率、L2 换金标 |Δ|、L3 种子 SD。
- **假设(探索性)**:敏感性不局限于稀有关系/长文档切片;
  若局限于某切片,如实报告并相应收缩"全局敏感性"措辞。

**成本合计**:R1 ≈ 0(公开预测文件若需下载另计);R2 ≈ 0(纯后处理,依赖 HacRED 15 种子批次);
R3 ≈ 0(纯后处理)。三项均不占用新 GPU 时,不改变 cloud-a 批次顺序。

## 修订 7(2026-10-03,D5 执行地点改本地、任何本地推断之前)

**修订内容**:D5 推断从云端 cloud-a 改为本地工作站执行;两处随之调整,其余冻结设计
(数据、提示、对照矩阵、解析纪律、bootstrap)全部不变。

1. **精度:FP16 → NF4 量化**。
   查证:本地 GPU 为 RTX 5060 Laptop(8,151 MiB),FP16 的 7B 权重(≈15.2 GiB)
   物理放不下;云端实例按用户指示停用。本地 bitsandbytes(Windows 官方 wheel)可用。
   推断改为 **NF4 量化(double-quant,compute dtype FP16)+ greedy(温度 0)**,
   模型、提示、解码策略不变。
   解读纪律:量化属"预测生成方式"的变化,审计对象仍是预测集合,契约审计逻辑不变;
   但 L2 与编码器 FP16 结果的量级对比须加谨慎措辞——量化引入额外预测噪声,
   若 |Δ| 更大不能全部归因于契约敏感性,该限制写入报告与论文限制节。

## 修订 22(2026-10-06,P1 跨任务结果落盘——H-X1 强负相关(显著),H-X2 无翻转;命题边界重构)

  r = **−0.963**(p=0.0021,n=6)——与预登记方向(ρ≥0.7 正相关)**完全相反**。

- **H-X2 无翻转**:6 对中 0 对发生 rank flip(3 对力臂超阈亦无翻转);

1. P1 的 leverage 定义(RE 用"分歧对重叠")与分类/NER 的 Jaccard 误差集重叠

2. 逐样本层(分类/NER)契约敏感性由**模型能力差**主导(强模型对排序稳),

3. 结论收缩:力臂定律的 RE 形式(分歧对重叠,金标杠杆)维持四基准证据;
   跨任务形式重构为"误差集几何与排名稳定性的关系"——方向相反但可统一于
   投影几何叙事(重叠高→共线→稳;本 P1 数据支持前半句的否定形式)。
